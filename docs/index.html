Bull Board Standalone

Multi-Instance Redis & Bull Queue Management Platform inspired by RedisInsight. Documentation & Web Portal is currently in progress.

🚀 Multi-Instance Redis

Connect and switch between unlimited Redis servers and DB indexes dynamically.

🗂️ Auto-Prefix Grouping

Automatic queue discovery grouped by prefixes (bull, ticketing, etc.) in sidebar.

🐳 Ultra-Lightweight Image

Docker container optimized to just 32MB download size and port 5541.

⚡ Native SQLite Store

Zero-dependency native SQLite persistence for instances configuration.

$ docker run -d -p 5541:5541 bull-board:latest
